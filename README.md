# PPA Risk Expert Consultation — sitio público

Sitio estático para publicar la página de acceso general e incrustar la web app de Google Apps Script.

## Configuración

1. Desplegar el proyecto privado de Apps Script.
2. Copiar la URL `/exec` en `app-config.js`.
3. Publicar este directorio en GitHub Pages, Netlify o el hosting estático elegido.

El sitio no contiene el código privado ni credenciales. Solo conoce la URL pública del despliegue.
